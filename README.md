# WorthIt

My app helps gamers on a budget decide which Steam games to buy this week by matching highly rated games to the genre, budget, and operating system they choose, as well as checking if a game is on sale.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
My users consist of PC/Laptop gamers that are looking for a new game but can't reach a confident decision. My users would use my app to account for their genre preferences, budget, and their operating system. This will allow my users to view high-rated games that match their liking.

## What it does
My app answers three questions:
1. **Sub-question 1:** Fit: which highly rated games match the genre and budget the gamer types in?
2. **Sub-question 2:** Compatibility: which of them run on the gamer’s operating system (Windows, Mac, Linux, etc.)?
3. **Sub-question 3:** Deals: which of them are on sale today, and how close is it to its lowest price ever (CheapShark)?
   
## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
